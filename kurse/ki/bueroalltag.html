Kapitel 1 · KI in deinem Alltag

Wo steckt KI im Büroalltag?

Nach dieser Einheit kannst du …

  • eine feste Automatisierungsregel von einem aus Daten gelernten Muster unterscheiden;
  • KI-Anwendungen im kaufmännischen Alltag erkennen;
  • begründen, wann ein Mensch das Ergebnis prüfen sollte.

Automatisch ist nicht immer KI

Montagmorgen im Büro: Eine Rechnung bekommt automatisch einen Rabatt. Eine E-Mail wird als Reklamation einsortiert. Ein Textassistent entwirft eine Antwort. Alles passiert mit Software – aber dahinter können unterschiedliche Verfahren stecken.

Künstliche Intelligenz ist ein Oberbegriff für unterschiedliche Verfahren, zum Beispiel zum Erkennen von Mustern, Verarbeiten von Sprache oder Planen von Handlungen. Wo genau die Grenze verläuft, hängt auch von der verwendeten Definition ab.

Für den Einstieg hilft eine konkrete Frage: Folgt das Programm einer direkt vorgegebenen Regel, oder nutzt es ein Modell, das aus Beispielen gelernt hat? Das unterscheidet einfache Automatisierung von maschinellem Lernen. Nicht alle KI-Verfahren lernen aus Daten.

Was bedeutet „Modell“?

Ein Modell bildet Zusammenhänge vereinfacht ab. Beim maschinellen Lernen werden seine Einstellungen anhand von Daten angepasst. Danach kann es zum Beispiel einschätzen, ob eine neue E-Mail eher eine Bestellung oder eine Reklamation ist. Diese Einschätzung kann falsch sein.

Drei Fälle aus deinem Büro

Fall 1 · Rechnungsbearbeitung

„Ab 1.000 € gibt es 5 % Rabatt.“

Die Software prüft den Betrag und berechnet den Rabatt nach dieser hinterlegten Regel. Dafür muss sie nichts aus früheren Rechnungen lernen. Das ist eine einfache regelbasierte Automatisierung.

Fall 2 · Kundenservice

„Diese Nachricht ist vermutlich eine Reklamation.“

Das System wurde mit vielen bereits zugeordneten Nachrichten trainiert. Es erkennt sprachliche Muster und schlägt für eine neue Nachricht die Kategorie „Reklamation“ vor. Hier wird maschinelles Lernen eingesetzt. Ungewöhnliche Formulierungen können zu Fehlern führen.

Fall 3 · Eine Antwort formulieren

„Schreibe eine freundliche Antwort an den Kunden.“

Ein Sprachmodell erzeugt einen Textentwurf aus deinem Auftrag und dem mitgegebenen Kontext. Ein überzeugender Text ist aber noch kein Beleg für richtige Aussagen. Prüfe insbesondere Termine, Beträge und Zusagen. Nutze zum Üben erfundene Daten und gib keine vertraulichen Kundendaten ein.

Du bleibst verantwortlich: Ob ein Betrieb eine Erstattung zusagt, entscheidet sich nicht daran, wie höflich der Text klingt. Zuständigkeit und betriebliche Regeln müssen geklärt sein.

Jetzt bist du dran

Drei kurze Situationen. Wähle jeweils eine Antwort und lies die Erklärung. Du kannst deine Auswahl danach ändern.

Aufgabe 1 von 3

Die Rechnungssoftware zieht ab 1.000 € immer 5 % ab. Was lässt sich daraus schließen?

Aufgabe 2 von 3

Ein System lernt aus zugeordneten E-Mails und sortiert neue Nachrichten. Was ist dabei wichtig?

Aufgabe 3 von 3

Der Textassistent verspricht eine Erstattung von 200 €. Der Betrag stand nicht in deinem Auftrag. Was tust du?

Eine Hilfe für alle drei Aufgaben

Frage dich: Woher kommt die Entscheidung? Ist die Regel fest vorgegeben? Wurde ein Muster aus Beispielen gelernt? Und welche Folgen hätte ein Fehler für Kundschaft oder Betrieb?

Deine Antworten werden nicht übertragen. Beim Verlassen oder Neuladen dieser Seite werden sie zurückgesetzt.

Das nimmst du mit

Eine feste Regel automatisiert einen bekannten Ablauf. Ein gelerntes Modell nutzt Muster aus Beispielen. Beide können Teil derselben Anwendung sein. Bei wichtigen Ergebnissen prüfst du Inhalt, Folgen und Zuständigkeit.

Transferfrage: Welche Aufgabe in deinem Ausbildungsbetrieb könnte Unterstützung gebrauchen – und was würdest du dabei selbst kontrollieren?
